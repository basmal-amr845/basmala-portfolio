# Basmala Amr — Creative Portfolio

A beginner-friendly bilingual Arabic/English personal portfolio made with HTML and CSS.

## Files
- `index.html` — page content and sections.
- `style.css` — colors, layout, responsive styles, and small CSS animations.

## Personalize before publishing
1. Replace the email placeholder `ADD-YOUR-EMAIL@example.com` in `index.html` with your email.
2. Replace `ADD-YOUR-PHONE` in the `tel:` link and the visible phone placeholder with your phone number.
3. To add your photo, put an image in this folder (for example `basmala.jpg`) and replace the contents of `.photo-placeholder` in `index.html` with `<img class="profile-photo" src="basmala.jpg" alt="Basmala Amr">`. Then add `.profile-photo { width:100%; height:100%; object-fit:cover; border-radius:inherit; }` to `style.css`.
4. Update the sample projects to match work you have actually completed.

Open `index.html` in a browser to preview the site.
